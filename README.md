## Cambiar precios

Abrir `app.js` y editar el arreglo `BUSINESS.packages` al inicio del archivo. Cada producto contiene nombre, número de personas, precio y descripción.

## Publicar en GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir todos los archivos conservando las carpetas.
3. Abrir **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Elegir la rama `main` y la carpeta `/ (root)`.
6. Guardar. GitHub mostrará el enlace público.

## Recomendación antes de publicar

Confirmar los precios, tamaño real de las porciones, horarios máximos, zonas exactas de delivery y procedencia de los ingredientes. No anunciar una procedencia específica —por ejemplo, choclo de Chingas— hasta tener asegurado ese proveedor.
